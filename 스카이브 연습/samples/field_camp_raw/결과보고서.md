# FIELD CAMP 제조 공정 시뮬레이션 결과보고서

- 기간: 2025.07 (3주)
- 유형: 산학 연계 캠프 (5인 1팀)

## 1. 과제
가상 제조 라인의 시간당 생산량이 목표에 못 미치는 원인을 찾고 개선안을 제시한다.

## 2. 진행 내용
우리 팀은 현장 자료를 바탕으로 공정별 처리 시간 분포를 추정하고 Arena로 생산 라인 모델을 작성하였다.
모델 검증 후 병목 공정(3번 공정)의 설비 추가, 작업 순서 변경, 버퍼 확대 세 가지 시나리오를 비교하였다.

## 3. 결과
- 기준안 대비 시간당 생산량 132% 개선 (설비 추가 + 버퍼 확대 조합)
- 설비 추가 단독은 118%, 작업 순서 변경 단독은 104%

## 4. 소감
시뮬레이션으로 개선안을 먼저 검증할 수 있다는 점이 인상적이었다.
