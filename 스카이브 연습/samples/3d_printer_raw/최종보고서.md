# 3D 프린터 PHM 이상탐지 시스템 최종보고서

- 기간: 2025.03 ~ 2025.06
- 소속: 기계공학과 캡스톤디자인 (4인 팀)

## 1. 배경 및 문제 정의
FDM 방식 3D 프린터는 노즐 막힘, 히팅베드 온도 이탈 등으로 출력 불량이 자주 발생한다.
기존에는 출력이 끝난 뒤 육안으로만 불량을 확인해 재료와 시간이 낭비되었다.
본 프로젝트는 출력 중 센서 데이터로 이상을 실시간 탐지하는 것을 목표로 한다.

## 2. 팀 구성 및 역할
| 이름 | 역할 |
|---|---|
| 김민수 | 센서 데이터 수집 및 전처리, Autoencoder 기반 이상탐지 모델 구현, 실시간 추론 서버 |
| 이서연 | 하드웨어 센서 부착 및 데이터 라벨링, 정상/불량 출력 실험 |
| 박지훈 | 발표자료 작성, 보고서 정리 |
| 최유나 | 임계값 검증 실험 보조 |

## 3. 방법
- 온도 센서 2종과 진동 센서 1종의 데이터를 50Hz로 수집
- 윈도우(2초) 단위 통계 특징(평균, 표준편차, 최대값) 추출
- 정상 출력 데이터만으로 Autoencoder를 학습하고 재구성 오차를 이상 점수로 사용
- 검증 데이터에서 임계값을 조정하고 FastAPI 기반 실시간 추론 서버에 탑재

## 4. 결과
- 불량 탐지 F1-score: 기준 모델(단순 임계값) 0.71 → 제안 모델 0.86
- 추론 지연 평균 42ms
- 불량 발견 시점: 출력 종료 후 → 출력 중 평균 3분 이내

## 5. 한계
