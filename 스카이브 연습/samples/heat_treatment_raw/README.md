# 열처리 공정 이상탐지 (개인 프로젝트)

- 작성자: 김민수 (1인 프로젝트)
- 기간: 2025.09 ~ 2025.11
- 유형: 자율 프로젝트

## 배경
열처리로의 온도 로그는 규칙 기반 알람(설정 온도 ±5도 이탈)만 사용하고 있어, 서서히 벗어나는 이상은 놓친다는 문제가 있었다.

## 한 일
- 공개 열처리 공정 온도 로그를 수집하고 정상/이상 구간을 직접 라벨링
- 온도 변화율과 구간 편차를 특징으로 만들어 Isolation Forest로 이상 점수 산출
- 규칙 기반 알람과 같은 데이터로 재현율 비교

## 결과
- 이상 구간 재현율: 규칙 기반 0.64 → 제안 방식 0.91
- 오탐률은 규칙 기반과 비슷한 수준(둘 다 약 5%)
