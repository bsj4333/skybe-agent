# 건설장비 유압 시스템 PHM 데이터 분석 (교내 산학 과제)

- 기간: 2024.03 ~ 2024.06
- 유형: 산학 과제, 3인 팀 (김민수, 정우진, 한소영)

## 목표
굴착기 유압 시스템의 압력·온도 센서 로그로 고장 징후를 사전에 찾는다.

## 역할 분담
| 이름 | 담당 |
|---|---|
| 김민수 | 유압 압력 센서 데이터 EDA, 가동 상태 분할 기준 정의, 이상 구간 라벨링 규칙 작성 |
| 정우진 | LSTM 기반 이상 예측 모델 구현 |
| 한소영 | 중간·최종 보고서 작성, 발표 |

## 결과
- 가동 상태(공회전/굴착/이동)를 분할해서 학습한 뒤 이상 탐지 F1-score가 0.62에서 0.78로 향상됨
- 최종 발표에서 협력 기업 담당자 피드백을 받음
