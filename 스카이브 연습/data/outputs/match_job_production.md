# 매칭 결과

다음은 공고의 요구사항과 지원자의 경험을 매칭한 결과입니다.

### Responsibilities
1. **생산 설비 및 공정 데이터 분석을 통한 품질 이상 조기 탐지**
   - [3d_printer_raw] 3D 프린터의 출력 중 센서 데이터를 활용하여 불량을 실시간으로 탐지하는 시스템을 개발하였습니다. 센서 데이터를 50Hz로 수집하고, Autoencoder 기반 이상탐지 모델을 구현하여 불량 탐지 F1-score를 기준 모델 0.71에서 제안 모델 0.86으로 향상시켰습니다. (출처: 최종보고서.md)

2. **생산 라인 병목 분석 및 공정 개선안 도출**
   - [field_camp_raw] 가상 제조 라인의 시간당 생산량 개선을 위한 시뮬레이션 결과 보고서를 작성하였습니다. 공정별 처리 시간 분포를 추정하고 Arena로 생산 라인 모델을 작성하여 병목 공정의 설비 추가, 작업 순서 변경, 버퍼 확대 시나리오를 비교하였습니다. (출처: 결과보고서.md)

3. **개선안의 시뮬레이션 기반 사전 검증**
   - [field_camp_raw] Arena를 사용하여 시뮬레이션을 통해 병목 공정 개선안을 검증하였습니다. 설비 추가와 버퍼 확대 조합으로 시간당 생산량을 132% 개선하였습니다. (출처: 결과보고서.md)

### Required Skills
1. **이공계 학사 이상**
   - 해당 경험 없음

2. **Python 등을 활용한 데이터 분석 역량**
   - [3d_printer_raw] Python을 활용하여 센서 데이터 수집 및 전처리, Autoencoder 기반 이상탐지 모델을 구현하였습니다. (출처: 최종보고서.md)

### Preferred Skills
1. **제조 현장 데이터 또는 시뮬레이션 프로젝트 경험**
   - [3d_printer_raw] 3D 프린터의 센서 데이터를 활용한 이상탐지 시스템 개발 경험이 있습니다. (출처: 최종보고서.md)
   - [field_camp_raw] 제조 공정 시뮬레이션 프로젝트 경험이 있습니다. (출처: 결과보고서.md)

2. **팀 프로젝트에서 본인의 역할을 명확히 설명할 수 있는 분**
   - [3d_printer_raw] 팀 프로젝트에서 센서 데이터 수집 및 전처리, Autoencoder 기반 이상탐지 모델 구현, 실시간 추론 서버 역할을 담당하였습니다. (출처: 최종보고서.md)

이와 같이 지원자의 경험은 공고의 여러 요구사항과 잘 부합합니다.
