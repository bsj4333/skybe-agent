# 머신러닝 수업 노트: 과적합과 정규화 (작성: 김민수)

- 수업: 머신러닝개론, 2024년 2학기

## 정리한 내용
- 편향-분산 트레이드오프: 모델이 복잡할수록 분산이 커지고 검증 성능이 떨어진다.
- k-겹 교차검증으로 데이터를 나눠 평균 성능을 보면 우연한 분할의 영향이 줄어든다.
- 정규화(L1, L2)는 가중치에 페널티를 줘서 과적합을 줄인다.

## 헷갈렸던 부분
- L1과 L2가 왜 다르게 동작하는지 직관적으로 설명하지 못했다. L1은 가중치를 0으로 만들어 변수 선택 효과가 있다는 것까지만 이해했다.
- 다음 주에 등고선 그림으로 다시 정리하기로 했다.

## 배운 점
학습 데이터 성능만 보면 안 되고, 반드시 분리된 검증 데이터로 성능을 확인해야 한다는 것을 배웠다.
