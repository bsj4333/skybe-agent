# 3D 프린터 PHM 이상탐지
> 3D 프린터 센서 데이터로 출력 불량을 실시간 탐지하는 시스템 개발 (샘플 데이터)

## Overview
- 기간: 2025.03 ~ 2025.06
- 유형: 팀 프로젝트 (4명)

## Problem
출력 중 노즐 막힘·온도 이상으로 불량이 나도 출력이 끝난 뒤에야 발견되어 재료와 시간이 낭비됨.

## My Role
센서 데이터 수집·전처리와 이상탐지 모델(Autoencoder) 구현, 실시간 추론 파이프라인 담당.

## Action
- 온도·진동 센서 데이터 노이즈 제거 및 윈도우 단위 특징 추출
- Autoencoder 재구성 오차 기반 이상 점수 산출
- 임계값을 검증 데이터로 조정하고 실시간 추론 서버 구현

## Results
- 불량 탐지 F1-score 0.71 → 0.86
- 불량 발견 시점을 출력 종료 후에서 출력 중 평균 3분 이내로 단축

## Skills / Tools
Python, PyTorch, pandas, FastAPI

## Lessons
임계값 하나가 현장 오탐률을 좌우하므로 모델 성능보다 운영 기준 설계가 중요하다는 것을 배움.
