# FIELD CAMP 공정 시뮬레이션
> Arena로 생산 라인을 모델링하고 병목을 찾아 생산량을 개선한 캠프 프로젝트 (샘플 데이터)

## Overview
- 기간: 2025.07 (3주)
- 유형: 산학 연계 캠프, 팀 프로젝트 (5명)

## Problem
가상 제조 라인에서 특정 공정에 대기열이 몰려 생산량이 목표에 못 미침.

## My Role
Arena 시뮬레이션 모델 구축과 시나리오 비교 실험 담당. 현장 데이터 수집은 다른 팀원이 담당.

## Action
- 공정별 처리 시간 분포를 적합해 시뮬레이션 모델 작성
- 병목 공정의 설비 추가·배치 변경 시나리오 3가지 비교

## Results
- 시간당 생산량 기준 132% 개선안 도출

## Skills / Tools
Arena, 통계 분석, Excel

## Lessons
개선안은 시뮬레이션으로 먼저 검증하면 현장 투자 리스크를 줄일 수 있음을 배움.
